# 💳 Online Payment Fraud Detection System

## 📝 Description
This project is an **Online Payment Fraud Detection System** built using **Python**, **Machine Learning**, and **Flask**.  
It analyzes payment transactions to detect **fraudulent activity** in real-time. ⚡  

The model is trained on a Kaggle dataset and exposes a **REST API** via Flask for predictions.

---

## ✨ Features
- 🔹 Detects fraudulent payment transactions  
- 🔹 Built with Python ML libraries: **scikit-learn**, **pandas**, **numpy**  
- 🔹 Real-time prediction via **Flask REST API** 🖥️  
- 🔹 Preprocessing and feature engineering included 🧹  
- 🔹 Model evaluation with accuracy, precision, recall, F1-score 📊  

---

## 🛠️ Tech Stack
- **Programming Language:** Python 🐍  
- **Machine Learning Libraries:** scikit-learn, pandas, numpy 📊  
- **Web Framework:** Flask 🌐  
- **Dataset:** Kaggle Credit Card Fraud Detection Dataset 💾  
- **Tools:** Jupyter Notebook, Git, GitHub 🐙
